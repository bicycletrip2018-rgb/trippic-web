# 트립픽 TRIPPIC — 소개 페이지

`https://bicycletrip2018-rgb.github.io/trippic-web/` 에 올라가는 **한 장짜리 소개
페이지**입니다. 앱 저장소(비공개)와 **따로** 둡니다 — 여기 올라가는 것은 공개될
것뿐이고, 기획·서버·앱 코드는 들어오지 않습니다.

## 파일

| | |
|---|---|
| `index.html` | 소개 페이지 |
| `invite.html` | **초대받은 사람이 보는 화면** — `?invite=CODE` 를 읽어 어떤 스페이스인지 보여 줍니다 |

## 고칠 때 — `invite.html`

앱을 받을 수 있게 되면(TestFlight 또는 스토어) **`APP_LINK` 한 줄만** 채우면
"앱에서 수락하기" 버튼이 생깁니다. 비워 두면 *"아직 앱을 받으실 수 없습니다"* 라고
정직하게 말합니다 — 없는 버튼을 만들지 않습니다.

★ `invite.html` 은 **바깥 자원을 하나도 안 부릅니다**(글꼴 CDN 도). 초대 코드가
  주소에 실려 있어서, 바깥으로 나가는 요청에 주소가 묻어 나가면 **코드가 샙니다.**
  `referrer: no-referrer` 도 같은 이유입니다.

## 고칠 때

- 스토어가 열리면 `index.html` 안의 **앱 스토어 주소 두 줄**만 채우면 버튼이
  "출시 예정"에서 실제 링크로 바뀝니다.
